<WritingBlock id="63821" variant="document"># Minecraft Trident Blocking Plugin

SpearBlock is a lightweight Minecraft plugin for Paper servers that prevents players from crafting tridents and removes tridents from generated loot. It helps server administrators restrict trident availability by blocking trident crafting recipes and filtering tridents out of loot generation.

## Install

1. Download the compiled SpearBlock JAR file.
2. Stop your Minecraft Paper server.
3. Place the JAR file into your server's `plugins` folder.
4. Start or restart your server.
5. Check the server console to verify that the plugin has loaded successfully.

## Use

1. Install SpearBlock on your Paper server.
2. Start the server with the plugin enabled.
3. Trident crafting results will be blocked automatically.
4. Tridents found in generated loot will be removed automatically.
5. No configuration or additional commands are required.

Note: This version specifically blocks the vanilla Minecraft TRIDENT material. It does not block custom items from other plugins that are merely named or designed as spears.
